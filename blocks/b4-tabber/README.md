# b4-tabber

Custom **tabs** block. 

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row, one cell of content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Ice background | `ice` |
| Small tab label | `label-s` |
| No lead title | `nolead` |
| Panel compact | `pc` |
| List label as title | `ltitle` |
| Tab label letter spacing 10 | `nls-10` |
| Letter spacing 0 | `ls-0` |
| Letter spacing 5 | `ls-5` |
| Letter spacing 7 | `ls-7` |
| Letter spacing 10 | `ls-10` |
| Letter spacing 12 | `ls-12` |
| Letter spacing 15 | `ls-15` |
| Letter spacing 20 | `ls-20` |
| Letter spacing 25 | `ls-25` |
