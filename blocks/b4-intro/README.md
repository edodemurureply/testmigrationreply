# b4-intro

Custom **columns** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

| Variation | Option class |

| Ice band | `ice` |
| Dark band | `dark` |
| Eyebrow label | `eyebrow` |
| Mid spacing | `mid` |
| Top spacing | `top` |
| Top and bottom spacing | `tb` |
| No top spacing | `top0` |
| No bottom spacing | `bot0` |
| Letter spacing 0 | `ls-0` |
| Letter spacing 5 | `ls-5` |
| Letter spacing 7 | `ls-7` |
| Letter spacing 10 | `ls-10` |
| Letter spacing 12 | `ls-12` |
